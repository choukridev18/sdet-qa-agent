# Quiz

Quiz de compréhension sur l'étape en cours. Une question à la fois.

1. Lis le README de l'étape (`docs/etapes/`) — rubrique « À savoir expliquer ».
2. Pose **une** question ouverte. Pas de QCM. Attends la réponse.
3. Après sa réponse : juste / partiel / faux, puis corrige en 3–5 phrases max.
4. Enchaîne seulement s'il veut continuer, ou s'il n'a pas encore tenu les points de l'étape.
5. Si une notion est fragile, ajoute-la dans `docs/suivi/a-retravailler.md`.
