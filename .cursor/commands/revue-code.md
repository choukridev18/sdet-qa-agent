# Revue de code

Revue senior du code que Choukri vient d'écrire ou de coller.

1. Lis les fichiers concernés. N'invente pas le contenu.
2. Commence par ce qui est bien (1–3 points concrets).
3. Ensuite **3 remarques maximum**, classées par importance (bug / lisibilité / testabilité / typage / erreurs).
4. Ne réécris pas le fichier. Indique où changer et pourquoi.
5. Si un choix est défendable en entretien, dis : « Note ça, c'est une question d'entretien probable. » et propose une ligne pour `docs/DECISIONS.md`.
