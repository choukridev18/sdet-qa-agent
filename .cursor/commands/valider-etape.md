# Valider étape

Vérifie si l'étape en cours peut être close.

1. Lis le README de l'étape (livrables + « Réussi quand ») et `docs/suivi/progression.md`.
2. Coche avec Choukri chaque critère. Demande preuve (commande, test, fichier), ne te fie pas à une affirmation.
3. Fais un mini-quiz sur « À savoir expliquer ». Si ça ne tient pas : ne valide pas, réexplique.
4. Si OK : mets à jour `docs/suivi/progression.md`, propose le tag Git `phase-N`, ouvre le README de l'étape suivante, propose un découpage, laisse-le choisir.
5. Si KO : liste ce qui manque, une tâche à la fois.
