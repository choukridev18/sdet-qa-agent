# Indice

Choukri bloque. Donne **un seul** indice, au niveau demandé (sinon le plus bas pas encore donné).

1. Lis son code et `docs/suivi/progression.md`. Ne suppose pas ce qu'il a écrit.
2. Niveau 1 — direction (doc, fichier, idée). Pas de code.
3. Niveau 2 — squelette (signature, étapes, pseudo-code). Pas la solution.
4. Niveau 3 — uniquement le fragment bloquant, court, à adapter.

Dis clairement le niveau. N'enchaîne pas avec le niveau suivant dans le même message.
