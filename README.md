# Projet SDET — Agent QA autonome

Portfolio SDET : un agent qui teste une application web (Playwright + LLM) et mesure lui-même son efficacité.

Le code applicatif n'existe pas encore. Choukri l'écrit, étape par étape, avec un mentor Cursor.

## Routine

1. Nouvelle conversation Agent → `/start-session`
2. Un incrément de 15–45 min, que tu codes toi-même
3. Fin de séance → `/end-session`

Autres commandes : `/indice` `/revue-code` `/quiz` `/valider-etape`

## Où regarder

| Fichier | Rôle |
| --- | --- |
| `docs/projet-sdet-brief.md` | Brief complet (ne pas modifier) |
| `docs/suivi/progression.md` | Où tu en es |
| `docs/etapes/` | Objectif, livrables, critères par étape |
| `docs/DECISIONS.md` | Choix techniques et raisons |
| `AGENTS.md` | Consigne courte pour n'importe quel agent |

Durée visée : 6–8 semaines. Version présentable dès la fin de l'étape 5.
