# Étape 2 — Les outils de l'agent, sans IA

## Objectif

Construire les « mains » de l'agent avant son « cerveau ».

## Livrables

- Couche navigateur : naviguer, cliquer, remplir, lire la page sous forme compacte, erreurs console/réseau, déclarer un bug, terminer
- Registre d'outils au format API + exécution
- Script qui rejoue une suite d'actions écrite à la main

## Réussi quand

- Un parcours complet se rejoue sans IA
- Un outil en échec renvoie une erreur lisible sans planter
- La navigation hors de l'app est refusée

## À savoir expliquer

- Pourquoi une représentation compacte de la page plutôt que le HTML
- Pourquoi les erreurs sont renvoyées au modèle
