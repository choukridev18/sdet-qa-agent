# Étape 1 — L'application cible

## Objectif

Une petite application web réaliste et facile à tester, que Choukri connaît par cœur.

## Livrables

- App avec quelques parcours classiques (ex. connexion, catalogue et recherche, panier avec code promo, commande avec validation, formulaire de contact)
- Sélecteurs de test stables
- Moyen de remettre les données à zéro
- Mécanisme pour activer des bugs à la demande
- Suite de tests écrits à la main (unitaires et end-to-end)
- App lancée dans Docker

## Réussi quand

- L'app démarre d'une commande
- Les tests manuels passent de façon stable

## À savoir expliquer

- Pourquoi séparer la logique métier des routes
- Pourquoi ces tests manuels serviront de vérité terrain plus tard

## Plan de tâches

À proposer au début de l'étape. Laisser Choukri choisir le métier de l'app (ex. mini-boutique) et le framework (Flask convient).
