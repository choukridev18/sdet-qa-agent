# Étape 8 — Tester l'agent lui-même

## Objectif

Montrer qu'un SDET teste aussi ses propres outils.

## Livrables

- Tests de la boucle agent avec un faux modèle aux réponses scriptées
- Tests des outils, règles de sécurité, contrôles de tests générés, métriques
- Ces tests tournent en CI sans réseau ni clé API

## Réussi quand

- Bonne couverture du code de l'agent
- Tests rapides et déterministes

## À savoir expliquer

- Comment tester un système non déterministe : enveloppe déterministe, cœur statistique via le banc d'essai
