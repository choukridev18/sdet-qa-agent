# Étape 4 — Génération de tests

## Objectif

L'agent écrit des tests, les exécute et les corrige jusqu'à obtenir une suite stable.

## Livrables

- Outils d'écriture et d'exécution, limités à un dossier dédié
- Contrôles qui refusent les mauvais tests (sans assertion, attentes fixes, etc.)
- Vérification qu'une suite passe plusieurs fois de suite
- Suite générée et figée, référence pour l'étape 5

## Réussi quand

- Pour les principaux parcours, les tests générés passent de façon stable sur l'app saine
- Les tentatives de sortir du bac à sable échouent

## À savoir expliquer

- Comment on repère un test qui ne teste rien
- Pourquoi on ne fait pas aveuglément confiance au code généré
